Governance > New Record Type

Details Controls Retention Permissions

Details

Choose an existing record group or create one, then name your record type (Ex: Budget Record).

This will be auto-suggested based on record name

Controls

Choose how declared records of this type are protected in Box.

Retention

Link an existing retention policy from the catalog to this Record type.

Retention Policy Name and Description

Specify a unique and descriptive name for this retention policy.

Time Period

Specify the amount of time the content should be retained.

Start date

Choose the date used as the start of the retention time period.

Disposition Action

Specify the disposition action that should take place after the content has been retained for the specified time period.

Select Disposition Action

Notification

Select managed users who will receive a weekly disposition email notification. This email will remind them about files with retention periods scheduled to expire within the next 14 days.

Select Users To Receive Notifications

Permissions

Choose to enable for all managed users in your account or select users you choose
